# Enterprise Network Security Policy

Version: 3.0
Owner: Network Security Team
Department: Cyber Security
Effective Date: 2025-03-01
Review Date: 2027-03-01
Status: Active

## Remote Access

Employees shall use multi-factor authentication for remote access.

Administrators must review privileged user accounts every 30 days.

External vendors may access the corporate VPN only during approved maintenance windows.

## Encryption Requirements

Network administrators must use TLS 1.2 or higher for external communications.

Security teams should review firewall rules quarterly.
